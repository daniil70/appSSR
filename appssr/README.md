# AppSSR — макет

Каталог и менеджер программ SSR по ТЗ «AppSSR». Текущая версия — макет **без базы данных**:
все данные (пользователи, каталог, таблицы, настройки, журнал) хранятся в JSON-файле
`%APPDATA%\AppSSR\appssr-data.json`. Пароли хранятся только в виде scrypt-хэшей с солью.

Стек: Electron + React + TypeScript (Vite).

## Запуск

```bash
cd appssr
npm install
npm run dev          # Electron + Vite с горячей перезагрузкой
npm run dev:web      # только интерфейс в браузере (данные в localStorage, установка имитируется)
npm run build        # сборка dist/ и dist-electron/
npm run build:win    # установщик и portable-сборка для Windows (папка release/)
```

Вход: `admin` / `admin`. Можно зарегистрировать обычного пользователя — права на изменение
каталога ему выдаёт администратор в «Настройках».

## Что умеет

- **Авторизация и роли.** Администратор / пользователь; право «управление каталогом» выдаётся отдельно.
- **Каталог ПО.** Карточки с состояниями «Установить» → «Идёт установка» → «Открыть» / «Ошибка».
  Предзаполнены Ассессмент, Аналитика, LIFApp и BCApp (без репозитория — «Скоро»).
- **Установка.** Команда из карточки выполняется через `cmd.exe /c` в папке `C:\Games\AppSSR\apps`
  (меняется в настройках). Вывод и код возврата показываются в правой панели; повторная установка
  блокируется; статус «установлена» определяется по наличию файлов в папке программы.
- **Запуск / удаление.** «Открыть» запускает exe из карточки (если не найден — предлагает переустановку;
  если путь не задан — открывает папку). «Удалить» очищает папку программы после подтверждения.
- **Таблицы.** Ссылки на таблицы Synology с названием, описанием и разделом; открываются в браузере по умолчанию.
- **Настройки.** Папка установки, разделы каталога, пользователи и права, журнал изменений каталога.
- Лог установок и удалений: `%APPDATA%\AppSSR\logs\appssr.log`.

## Структура

```
appssr/
  electron/     main.ts (окно, IPC, проверка прав), preload.ts (мост), store.ts (JSON-хранилище), installer.ts (cmd/exe/удаление)
  shared/       types.ts (общие типы), seed.ts (стартовый каталог)
  src/          React-интерфейс: App.tsx, components/, styles.css, api.ts (мост + браузерный мок)
```
